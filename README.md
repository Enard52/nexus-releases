# NEXUS Releases

Public distribution point for the [NEXUS](https://github.com/Enard52/NEXUS) smart home app.

This repository holds the signed installers and auto-update manifests (`latest.yml`, `latest-linux.yml`) produced by the release workflows.

- Windows / Linux / Android downloads: see [Releases](https://github.com/Enard52/nexus-releases/releases/latest)
- Source code, docs and license: [Enard52/NEXUS](https://github.com/Enard52/NEXUS)
